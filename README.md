# DREAMSCAPE 🌌

A responsive interactive cosmic landing page made with plain HTML, CSS and JavaScript.

## Features
- Animated starfield with subtle cursor parallax
- Procedurally drawn glowing planet, orbit and satellite
- Five discoverable planetary sectors with changing details
- Optional locally generated ambient tone (off by default)
- Responsive layout and reduced-motion support
- No framework, build step, API key or external image assets required

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a repository named `dreamscape` in your GitHub account.
2. Upload `index.html`, `style.css`, `app.js` and `README.md` to its root.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Once deployment finishes, the site should appear at `https://YOUR-USERNAME.github.io/dreamscape/`.

The font import uses Google Fonts; system fallbacks are included. Visual effects are drawn locally on canvas.
